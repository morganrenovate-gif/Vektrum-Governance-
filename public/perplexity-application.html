Computer Usage Proof — How Perplexity Changed What We Built

Usage 1 AI Draw Control Brief — The Core Precondition

Perplexity sonar-pro is the first model in our fallback chain and powers the mandatory AI Draw Control Brief. For every release attempt, it reads the draw package and extracts: milestone completion %, lien waiver status, inspection sign-off, budget variance flags, and unresolved open items — then returns a structured risk score (0–100). If any critical risk flag is set, the release gate blocks automatically.

Harbor Draw #3 result: risk score 91/100 · no critical flags · gate clears in seconds vs. 2–3 day manual underwriter SLA
Usage 2 Multi-Provider Fallback Chain — Operational Resilience

Perplexity sonar-pro is primary in a three-provider chain (sonar-pro → claude-sonnet → gpt-4o). When any single provider has downtime, the brief runs on the next. This removed an entire reliability engineering workstream — we did not need to build our own document-analysis NLP pipeline or manage model inference infrastructure.

Scope change: 3–4 months of NLP infrastructure work eliminated; shipped in days instead
Usage 3 Made AI-Gated Release Commercially Feasible

Without Perplexity, every draw release would require a human underwriter to review the package before the gate could run — a 2–3 day SLA that would make Vektrum a bottleneck rather than an accelerator. sonar-pro's document reading capability made the AI precondition fast enough to be a gate condition, not a separate workflow step. This is what makes Vektrum's model viable: the AI informs the gate; the gate is deterministic; the funder decides.

Product model only exists because AI review is fast enough to be a synchronous gate precondition

Why This Can Become a Very Large Company

🏗️
Massive, Underdone Market

$550B+ annual US construction starts. Every construction loan has a draw process. The release-control layer has seen near-zero software investment — draw governance still runs on email, PDFs, and spreadsheets.

🔌
Rail-Agnostic = No Lock-In

Vektrum sits before Stripe, title, escrow, bank treasury, or any execution rail. Lenders keep their existing payment infrastructure and add release enforcement — no rip-and-replace, minimal friction to adopt.

📈
Per-Release Fee on Loan Volume

0.65–1.00% per release. A single construction lender with $100M in active construction loans running draws twice per year = ~$1.3M ARR per customer. High-frequency, high-margin on top of existing capital flows.

🛡️
Compliance + Audit Moat

Hash-chained audit evidence and LP-reportable release records become a compliance requirement for institutional lenders. First mover becomes the standard, the way Stripe became the default for online payments.

🤝
Network Effects via Partners

Each lender brings multiple deals. Each deal brings contractors proven on the platform. Title and escrow partners embed Vektrum into their workflows — distribution compounds with every integration.

🚧
No Comparable Competitor

Others (Procore, BuilderTrend, lien-waiver apps) track and manage. None enforce a server-side gate that is AI-informed, admin-proof, rail-agnostic, and hash-chained. Vektrum owns a category that does not yet have a winner.
